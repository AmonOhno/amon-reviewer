# React 共通UIコンポーネントのレビュー観点

React / TypeScript で作られた共通UIコンポーネントのPRをレビューしてください。
差分だけでなく、仕様書・呼び出し元・既存の類似コンポーネントなど、判断に必要なファイルは自由に読んでください。

## 必須観点

すべて確認し、該当する問題がなければ「問題なし」と書いてください。

1. **API（Props）設計**：Propsは最小限か。命名や形は既存コンポーネントと揃っているか。制御／非制御、ref やネイティブ属性の受け渡し
2. **実行時の防御**：型は実行時には保証されない。不正値・undefined・外部データへの備えがあるか。似た項目どうしで不正値の扱いが揃っているか
3. **ライフサイクル・実行順序**：よくある配置や呼び出し方（マウント順、effect の実行順、アンマウント）で壊れないか。エラーにならず黙って失敗する経路はないか
4. **アクセシビリティ**：コントラスト（WCAG AA）、キーボード操作、フォーカス管理、role / aria、スクリーンリーダーでの読み上げ
5. **パフォーマンス**：頻繁に呼ばれる処理（scroll・resize・入力）に重い処理がないか。不要な再レンダリングがないか
6. **仕様との整合**：仕様書があれば実装と食い違っていないか。仕様に書かれていない挙動はないか
7. **テスト**：振る舞いを検証しているか。境界値・不正値を含むか。実時間の待機に頼らず、速く安定しているか

## 自由観点

上記以外でも、バグ・保守性・セキュリティなどの問題に気づいたら指摘してください。

## 出力

日本語の Markdown で出力してください。各指摘には重大度（must / should / nit）と該当箇所（ファイル:行）を付けてください。
