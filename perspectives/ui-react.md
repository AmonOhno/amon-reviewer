# React 共通UIコンポーネントのレビュー観点

React / TypeScript の共通UIコンポーネントのPRをレビューしてください。

## 観点

- **API（Props）設計**：最小限か、既存と揃っているか、制御／非制御、ref とネイティブ属性の受け渡し
- **拡張性**：特定の画面・業務の都合が混ざっていないか、合成やスタイルの上書きで拡張できるか
- **型と実行時の防御**：型は実行時に保証されない。不正値・null・外部データへの備え、似た項目での扱いの一貫性
- **状態とライフサイクル**：導出できる値を状態に持っていないか、effect の依存・実行順・クリーンアップ、黙って失敗する経路
- **アクセシビリティ**：role / aria、ラベル、キーボード操作、フォーカス管理、コントラスト、読み上げ
- **パフォーマンス**：不要な再レンダリング、頻繁に呼ばれる処理の重さ、大量データ
- **国際化**：文言や書式のハードコード
- **仕様・ドキュメントとの整合**：仕様書と実装の食い違い、破壊的変更
- **テスト**：振る舞いを検証しているか、境界値・不正値、実装の詳細や実時間への依存

上記以外でも、バグ・保守性・セキュリティなどの問題に気づいたら指摘してください。

## 出力

問題がある点だけを、日本語の Markdown で書いてください。問題がなければ「指摘なし」とだけ書いてください。
各指摘には重大度（must / should / nit）と該当箇所（ファイル:行）を付けてください。
