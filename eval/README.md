# 精度検証ケース

観点MDやプロンプトを変えたとき、レビューの精度が上がったか下がったかを確かめるためのケースです。

```
eval/<観点MDの名前>/<ケース名>/
├─ expected.md  # 期待される指摘
├─ fixture/     # サンプルPRで追加されるファイル
├─ base/        # PR前から main にあるファイル（省略可）
└─ context.md   # 呼び出し元の前提として渡す内容（省略可。省略時は Claude がリポジトリから確かめる）
```

```bash
scripts/eval.sh            # すべてのケース
scripts/eval.sh ui-react   # 観点MDごと
```

結果（各ケースの `runs/<日時>.md`）を `expected.md` と見比べ、拾えなかった件数（見逃し）と、的外れな指摘の件数（ノイズ）を数えます。
言い回しは問わず、同じ問題を指していれば拾えたと数えます。出力は毎回ばらつくので、比べるときは数回ずつ実行してください。

アプリ固有のケースは、各アプリのリポの `.amon-reviewer/eval/` に置いてください。
